# AudioBlocks — Artist Dashboard

This is the Next.js application for the AudioBlocks artist dashboard.

**For full setup instructions, architecture documentation, and contribution guidelines, see the [main README](../README.md) at the repository root.**

## Quick Start

From the `app/` directory:

```bash
# Install dependencies
npm ci --legacy-peer-deps

# Copy and configure environment variables
cp .env.example .env.local
# Edit .env.local with your values

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

## Available Scripts

- `npm run dev` — Development server
- `npm run build` — Production build
- `npm test -- --run` — Run tests once
- `npm run test:e2e` — End-to-end tests
- `npm run storybook` — Component explorer
- `npm run lint` — ESLint
- `npm run format` — Prettier

See the [root README](../README.md) for complete documentation.
